# ADR-012. Verificación pública en el navegador

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | Un tercero debe comprobar sin cuenta y sin confiar en la plataforma. |
| Drivers | DRV-001 |
| Alternativas | Subir el archivo al servidor para comparar. |
| Decisión | El verificador calcula SHA-256 en el navegador por fragmentos dentro de un Web Worker y compara con el manifiesto. |
| Justificación | Privacidad y confianza del verificador (RN-022). |
| Consecuencias positivas | El verificador no depende de ALETHEIA para el resultado. |
| Consecuencias negativas | SubtleCrypto.digest necesita el archivo completo en memoria; los archivos grandes requieren cálculo incremental (RT-003). |
| Riesgos | Biblioteca de hash incremental por elegir en la Etapa 4. |
| Fecha y responsables | 15/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Ninguna |
