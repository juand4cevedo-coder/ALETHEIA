# ADR-005. Cifrado por caso y eliminación por destrucción de llave

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | Se custodian datos sensibles y la eliminación debe ser demostrable. |
| Drivers | DRV-003 |
| Alternativas | Cifrado del servicio de almacenamiento solamente; borrar objetos uno por uno. |
| Decisión | Llave AES-256-GCM por caso, envuelta por una llave maestra en Key Vault; eliminar es destruir la llave envuelta. |
| Justificación | Una sola operación hace ilegible todo el caso, incluso copias. |
| Consecuencias positivas | Protección ante robo de base o almacenamiento. |
| Consecuencias negativas | Los respaldos conservan la llave envuelta durante su retención (RT-006). |
| Riesgos | Pérdida de la llave maestra (RSK-09). |
| Fecha y responsables | 15/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Ninguna |
