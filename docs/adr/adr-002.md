# ADR-002. Interfaz y API en el mismo origen detrás de Caddy

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | Las sesiones van en cookies y el instructor pide CORS y cabeceras de seguridad. |
| Drivers | DRV-004 |
| Alternativas | Dominios separados con CORS abierto; tokens en almacenamiento del navegador. |
| Decisión | Caddy sirve la interfaz y envía /api a FastAPI bajo aletheia.sbs. |
| Justificación | Menos superficie de ataque y sin tokens accesibles desde JavaScript. |
| Consecuencias positivas | CSRF mitigado por SameSite y verificación de Origin. |
| Consecuencias negativas | La interfaz depende de que Caddy esté arriba. |
| Riesgos | Error de CSP que bloquee la interfaz; se prueba en TT-008. |
| Fecha y responsables | 15/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Ninguna |
