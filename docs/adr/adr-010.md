# ADR-010. Adaptadores para almacenamiento, sellado, pagos y correo

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | Varios proveedores están por confirmar: pasarela, correo y autoridad de sellado. |
| Drivers | DRV-008 |
| Alternativas | Llamadas directas desde los servicios. |
| Decisión | Cada servicio externo vive detrás de una interfaz con implementación real y de pruebas. |
| Justificación | Permite Wompi o una entidad acreditada sin cambiar el modelo. |
| Consecuencias positivas | Pruebas sin red y cambio de proveedor por configuración. |
| Consecuencias negativas | Una capa más de código. |
| Riesgos | Interfaces demasiado genéricas; se diseñan por caso de uso. |
