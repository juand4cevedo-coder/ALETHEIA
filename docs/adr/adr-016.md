# ADR-016. Producción en Oracle Cloud con recursos Always Free

| Campo | Contenido |
| --- | --- |
| Estado | Reemplazado por ADR-017 |
| Contexto | Azure no concedió la cuenta gratuita y el pago por uso, unos 90.000 pesos al mes, no se puede cubrir antes del 1 de noviembre. Producción debe costar cero hasta la sustentación de diciembre, sin perder seguridad ni cambiar la arquitectura. |
| Drivers | DRV-003, DRV-006, DRV-009 |
| Alternativas | Mantener Azure con pago por uso; DigitalOcean; plataformas gratuitas como servicio; Oracle Cloud con recursos Always Free. |
| Decisión | Oracle Cloud en la región de Bogotá (sa-bogota-1), solo con recursos Always Free: una máquina ARM Ampere A1 de 2 OCPU y 12 GB con Docker Compose (Caddy, API, trabajador y PostgreSQL 18 en un volumen de bloque), Object Storage con el SDK de OCI para evidencias, paquetes y copias de respaldo, OCI Vault para la llave maestra y los secretos, e instance principals para acceder sin llaves guardadas. En desarrollo el almacenamiento usa disco local y se retira Azurite. Las imágenes se compilan para linux/arm64 y la cuenta nunca pasa a pago por uso. Donde ADR-005 y ADR-014 dicen Key Vault, se lee OCI Vault. |
| Justificación | Costo cero con más capacidad que la máquina B1ms prevista: 2 OCPU y 12 GB frente a 1 vCPU y 2 GiB. Conserva el principio de no guardar secretos en archivos y la arquitectura por adaptadores (ADR-010), y los datos quedan alojados en Colombia. Los adaptadores de almacenamiento y de llaves aún no existían, así que el cambio llega antes de escribir código atado al proveedor. |
| Consecuencias positivas | Producción sin costo hasta la sustentación y después; seis veces la memoria prevista; datos alojados en Colombia. |
| Consecuencias negativas | Se pierden los respaldos administrados de PostgreSQL: la copia diaria a Object Storage pasa a cargo del proyecto (TT-011). La API compatible con S3 de Object Storage exige llaves secretas de usuario, por eso se usa el SDK nativo de OCI, que no tiene emulador local. El almacenamiento gratuito de objetos es limitado. |
| Riesgos | Falta de capacidad ARM en Bogotá, región con una sola zona de disponibilidad (RT-009). Queda por verificar en TT-007 que OCI Vault envuelva con RSA-OAEP-256, para mantener ADR-014 sin cambios, y que Tink publique binarios para ARM con Python 3.14. |
