# ADR-004. Cadena de custodia de solo inserción con eliminación controlada

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | RN-006 exige un historial inmodificable y DAT-15 exige eliminarlo con el caso. |
| Drivers | DRV-001 |
| Alternativas | Borrado en cascada; conservar los eventos para siempre. |
| Decisión | Cada evento guarda el hash del anterior y el suyo; la inserción bloquea la fila del caso; un trigger rechaza UPDATE y DELETE salvo dentro de la función purge_case, que primero escribe la constancia. |
| Justificación | Resuelve la contradicción sin abrir una vía de borrado a la aplicación; aprobado por el patrocinador el 23/10/2026. |
| Consecuencias positivas | Alteraciones detectables y eliminación demostrable. |
| Consecuencias negativas | La función purge_case es código crítico de base de datos. |
| Riesgos | Error en la función; se prueba con casos de eliminación parcial. |
| Fecha y responsables | 23/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Reemplaza la redacción anterior de RN-006 (CR-002) |
