# ADR-003. PostgreSQL como cola de tareas

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | Sellos, exportes, correos y eliminaciones deben hacerse fuera de la petición. |
| Drivers | DRV-008, DRV-009 |
| Alternativas | Redis con una librería de colas; servicio de colas de Azure. |
| Decisión | Tabla jobs con FOR UPDATE SKIP LOCKED, clave de idempotencia y reintentos con espera creciente. |
| Justificación | El volumen previsto no justifica otra pieza; la tarea se encola en la misma transacción que la crea. |
| Consecuencias positivas | Una pieza menos que operar y pagar. |
| Consecuencias negativas | Menos rendimiento que una cola dedicada a gran escala. |
| Riesgos | Tareas atascadas; se liberan por tiempo de bloqueo. |
| Fecha y responsables | 15/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Ninguna |
