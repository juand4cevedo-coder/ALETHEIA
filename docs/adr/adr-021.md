# ADR-021. Rutas con React Router, datos con TanStack Query y estilos con tokens propios

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | Con HU-002 el frontend deja de ser una sola pantalla: el sitio público tiene inicio, precios y páginas legales, y después llegan el acceso y el espacio de trabajo. Hace falta decidir cómo se navega entre páginas, cómo se piden y se guardan en memoria los datos de la API y cómo se aplican los tokens del sistema de diseño, respetando la política de seguridad de contenido de Caddy, que solo admite scripts, estilos y fuentes del propio sitio. |
| Drivers | DRV-010 |
| Alternativas | Rutas: React Router o TanStack Router. Datos: TanStack Query o peticiones manuales con useEffect. Estilos: CSS Modules con variables propias, Tailwind o una librería de componentes. Fuente: Inter servida desde el sitio o desde Google Fonts. |
| Decisión | React Router 8.5.0 en modo de librería, con `createBrowserRouter` y las rutas en `src/routes/router.tsx`. TanStack Query 5.104.5 para todo dato de la API, usando las opciones que Hey API genera por operación (`listPlansOptions()` y siguientes); se considera vigente un minuto, lo mismo que la API permite guardar el catálogo. Estilos con CSS Modules y los tokens del documento de diseño como variables en `src/styles/tokens.css`. Inter Variable servida desde el propio sitio con `@fontsource-variable/inter` 5.3.0. Carpetas: `pages` para cada página, `layouts` para los marcos, `features/<dominio>` para componentes y lógica de un dominio y `config` para datos del sitio. |
| Justificación | React Router es el enrutador más usado y documentado de React, lo que pesa para un desarrollador que empieza con React. TanStack Query resuelve carga, error, reintento y memoria de los datos sin código propio, y Hey API ya genera sus opciones con los tipos del contrato. CSS Modules no agrega dependencias, aísla los estilos de cada componente y no necesita estilos en línea, que la política de Caddy bloquea; por la misma política la fuente se sirve desde el sitio. |
| Consecuencias positivas | Cada pantalla nueva sigue el mismo patrón: una ruta, una página y las consultas generadas. Ningún color, espacio ni duración se escribe fuera de los tokens. La interfaz funciona con la política de seguridad estricta, sin excepciones. |
| Consecuencias negativas | Tres dependencias de ejecución más en el frontend. Los estados de interfaz complejos se escriben a mano en CSS, sin una librería de componentes. |
| Riesgos | Que un cambio mayor de React Router o TanStack Query cambie su API: las versiones van fijas y se actualizan con la espera de ADR-019 y la CI en verde. |
| Fecha y responsables | 31/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Ninguna. |
