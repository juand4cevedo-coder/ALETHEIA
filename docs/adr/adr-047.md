# ADR-047. Informe PDF generado a partir del manifiesto exacto

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | HU-025 exige un informe PDF con declaración de alcance dentro del paquete. El contenido debe corresponder al mismo `manifest.json` cuya huella se guarda en `exports`, y mostrar los sellos y anclajes que realmente existen. |
| Drivers | DRV-001, DRV-004 |
| Alternativas | Redactar el informe desde consultas separadas a la base; generar HTML y convertirlo con un navegador; añadir un PDF fijo sin datos del paquete; generar el PDF directamente desde el manifiesto. |
| Decisión | Usar ReportLab 5.1.0 para generar una página PDF desde los bytes exactos y la huella SHA-256 del manifiesto de ADR-044. El informe muestra identificadores, fecha UTC, cantidad de evidencias, conteo de sellos obtenidos, pendientes y fallidos, estado real del anclaje y la huella de `manifest.json`. Incluye una declaración que limita la comprobación a coincidencia de bytes; no afirma autenticidad, procedencia, admisibilidad ni valor probatorio. Sin anclaje externo, indica expresamente el límite de la cadena ante quien controle la base. Se incrusta la fuente Vera incluida en ReportLab para conservar caracteres acentuados y se activa la salida reproducible del generador. |
| Justificación | Generar el informe desde el manifiesto evita que una consulta posterior muestre otro estado. La huella en el PDF permite identificar el manifiesto al que se refiere el informe, sin crear una dependencia circular: el manifiesto no contiene la huella del PDF. |
| Consecuencias positivas | La declaración y los estados técnicos se comprueban extrayendo el texto del PDF en pruebas. El ZIP de ADR-046 puede generar el informe si el llamador no lo aporta. |
| Consecuencias negativas | La biblioteca añade una dependencia a la imagen del backend. El informe no firma el paquete ni sustituye el sello RFC 3161 pendiente en DEP-04. |
| Riesgos | Un PDF puede parecer una certificación. El título y el texto delimitan su función informativa y prohíben inferir autenticidad o validez jurídica. |
| Fecha y responsables | 17/11/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Complementa ADR-044 y ADR-046. |
