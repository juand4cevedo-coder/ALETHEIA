# ADR-014. Biblioteca de cifrado por flujos

| Campo | Contenido |
| --- | --- |
| Estado | Propuesto |
| Contexto | El archivo debe cifrarse mientras llega, sin cargarlo completo. |
| Drivers | DRV-011 |
| Alternativas | Tink Streaming AEAD; cryptography con fragmentos y nonce por bloque. |
| Decisión | Elegir entre Tink Streaming AEAD y cryptography con AES-GCM por fragmentos tras la prueba técnica. |
| Justificación | Se elegirá la que tenga documentación oficial vigente, soporte para Python 3.14 y formato estándar. |
| Consecuencias positivas | Memoria constante en subidas grandes. |
| Consecuencias negativas | Si ninguna sirve, plan B: cifrar el archivo completo con tope de tamaño por plan. |
| Riesgos | RSK-02. |
| Fecha y responsables | 23/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Ninguna |
