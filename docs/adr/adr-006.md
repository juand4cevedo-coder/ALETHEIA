# ADR-006. Aislamiento con filtro por organización y Row-Level Security

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | El mayor riesgo de un servicio multiorganización es el acceso cruzado. |
| Drivers | DRV-002 |
| Alternativas | Solo filtros en el código; una base por cliente. |
| Decisión | Toda consulta filtra por organization_id y PostgreSQL aplica RLS con el valor fijado en cada transacción. |
| Justificación | Defensa en profundidad con costo bajo. |
| Consecuencias positivas | Pruebas de acceso cruzado más confiables. |
| Consecuencias negativas | Las consultas de la consola necesitan funciones especiales. |
| Riesgos | Política mal escrita; se prueba en CI con PostgreSQL real. |
| Fecha y responsables | 15/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Ninguna |
