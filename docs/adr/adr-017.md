# ADR-017. Producción en AWS con el plan gratuito

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | Oracle Cloud no tuvo capacidad ARM en Bogotá tras unas 16 horas de reintentos, y Google Cloud exige un prepago de 100.000 pesos que el proyecto no puede cubrir. La Etapa 2 necesita producción antes del 2 de noviembre, en un proveedor con capacidad disponible y sin pagos durante el proyecto. |
| Drivers | DRV-003, DRV-006, DRV-009 |
| Alternativas | Seguir reintentando en Oracle Cloud; Google Cloud con prepago; Azure con pago por uso; AWS con el plan gratuito. |
| Decisión | AWS en la región de Ohio (us-east-2) con el plan gratuito: una instancia EC2 t3.small x86 (2 vCPU y 2 GB) con Debian 13, volumen EBS gp3 de 30 GiB, IMDSv2 obligatorio e IP elástica; Docker Compose con Caddy, API, trabajador y PostgreSQL 18; Amazon S3 privado para evidencias, paquetes y copias de respaldo; AWS KMS con una llave RSA que envuelve con OAEP y SHA-256, de modo que ADR-014 no cambia; secretos en Parameter Store cifrados con KMS, y un rol de IAM de la instancia para acceder sin llaves guardadas. La instancia se amplía a m7i-flex.large solo para el lanzamiento y la sustentación. Las imágenes se compilan para linux/amd64 y en desarrollo el almacenamiento usa disco local. |
| Justificación | La capacidad está disponible de inmediato y el consumo estimado, unos 22 USD al mes, se descuenta de los 100 USD de crédito del plan gratuito, vigente hasta el 29/04/2027. Mantiene el principio de no guardar secretos en archivos y la arquitectura por adaptadores (ADR-010). Con x86 desaparecen los riesgos de compatibilidad de ARM. |
| Consecuencias positivas | Capacidad garantizada; servicios maduros y documentados; la misma imagen x86 en la CI, en desarrollo y en producción. |
| Consecuencias negativas | La copia de respaldo de PostgreSQL sigue a cargo del proyecto (TT-011). La instancia t3.small tiene 2 GB de memoria para cuatro contenedores. Los datos quedan en Estados Unidos, así que la política de tratamiento declara la transferencia internacional (Ley 1581 de 2012). |
| Riesgos | Que los créditos se agoten antes de la sustentación (RT-011): presupuesto mensual de 30 USD con alertas al 50 y 80 %. Que la memoria no alcance (RT-007): se mide con la prueba de carga. |
| Fecha y responsables | 29/10/2026, Juan Diego Acevedo Calderon |
