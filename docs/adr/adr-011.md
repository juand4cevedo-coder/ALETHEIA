# ADR-011. Producción en Azure con VM B1ms y servicios administrados

| Campo | Contenido |
| --- | --- |
| Estado | Reemplazado por ADR-016 |
| Contexto | Se perdió el acceso al beneficio estudiantil y el presupuesto es de 70.000 a 100.000 pesos. |
| Drivers | DRV-006, DRV-009 |
| Alternativas | DigitalOcean; plataformas como servicio. |
| Decisión | VM con Docker Compose, PostgreSQL flexible B1ms, Blob Storage y Key Vault con identidad administrada. |
| Justificación | Conserva la arquitectura, ofrece Key Vault e identidad administrada, y Azurite emula el almacenamiento en desarrollo. |
| Consecuencias positivas | Sin llaves en archivos y respaldos administrados. |
| Consecuencias negativas | Más piezas que configurar. |
| Riesgos | Cuenta no creada aún (RT-008). |
| Fecha y responsables | 20/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Reemplaza el plan con Azure for Students; reemplazada por ADR-016 (CR-003) |
