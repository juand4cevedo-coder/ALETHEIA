# ADR-008. Contrato OpenAPI como fuente única y errores Problem Details

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | Frontend y backend no pueden tener contratos distintos. |
| Drivers | DRV-010 |
| Alternativas | Tipos escritos a mano. |
| Decisión | FastAPI genera OpenAPI; el frontend genera tipos y cliente; los errores siguen RFC 9457. |
| Justificación | Una sola fuente de verdad, como pide la especificación de ingeniería. |
| Consecuencias positivas | Menos errores de integración. |
| Consecuencias negativas | Hay que fijar la herramienta de generación en TT-009. |
| Riesgos | Herramienta inmadura; se elige con documentación oficial. |
| Fecha y responsables | 15/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Ninguna |
