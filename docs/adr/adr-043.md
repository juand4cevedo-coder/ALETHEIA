# ADR-043. Identidad grafito y sistema de diseño

| Campo | Contenido |
| --- | --- |
| Estado | Propuesto |
| Contexto | La interfaz se apoyaba en un único azul sobre fondos azul oscuro, con focos de luz, halos y degradados decorativos. Se veía plana y genérica, poco acorde con un producto que custodia evidencia legal. Los textos tenían marcas de plantilla, como el punto medio usado como separador o los números de sección. |
| Drivers | Confianza del abogado, legibilidad en jornadas largas, rendimiento en celulares de gama media y coherencia entre la landing y el espacio de trabajo. |
| Alternativas | Tinta y lacre (negro con un rojo de sello y titulares en serifa); marfil y medianoche (fondo claro con fotografía real); grafito y estado. |
| Decisión | Identidad grafito y estado, en la línea de Resend, Better Stack y Revolut Business. Grafito en tres superficies; violeta solo para la acción y el foco; verde, ámbar y rojo solo para los estados. Geist y Geist Mono alojadas en el sitio. Íconos Phosphor más un juego propio para huella, sello, cadena y paquete. Sin efectos de luz decorativos. Se conserva la forma del logo y cambia su color. Reglas de redacción verificables. El detalle está en `docs/diseno/identidad-y-sistema-de-diseno.md`. |
| Justificación | El producto se explica mostrando su interfaz. Separar el color de la acción del color del estado evita que un verde se confunda con un botón. Menos efectos significan menos trabajo para el navegador y menos ruido para quien lee. |
| Consecuencias positivas | Un solo sistema para la landing, el espacio de trabajo y los correos; contraste AA medido en cada combinación; menos CSS y menos fuentes. |
| Consecuencias negativas | Hay que rehacer la landing y revisar todas las pantallas y sus pruebas. |
| Riesgos | Que el violeta se use fuera de la acción y pierda su significado: se revisa en cada PR. |
| Fecha y responsables | 11/11/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Reemplaza la paleta y los efectos de ADR-023 y ADR-041; conserva sus decisiones de estructura. |
