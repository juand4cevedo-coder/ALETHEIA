# ADR-007. Sesiones con JWT corto, renovación rotativa en cookies y Argon2id

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | El instructor pide JWT con renovación, cookies y hash de contraseñas. |
| Drivers | DRV-004, DRV-007 |
| Alternativas | Sesiones de servidor; bcrypt. |
| Decisión | JWT de 10 minutos, token opaco de 14 días con rotación y familias, Argon2id para contraseñas. |
| Justificación | OWASP recomienda Argon2id; la rotación detecta robo de tokens (CR-001). |
| Consecuencias positivas | Revocación efectiva y contraseñas resistentes. |
| Consecuencias negativas | Más lógica de sesión que probar. |
| Riesgos | Ninguno nuevo. |
| Fecha y responsables | 15/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | CR-001 |
