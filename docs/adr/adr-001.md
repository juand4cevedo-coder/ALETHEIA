# ADR-001. Monolito modular por capas en un monorepo

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | Una sola persona debe entregar un producto completo en 44 días y el instructor exige arquitectura por capas. |
| Drivers | DRV-007, DRV-008 |
| Alternativas | Microservicios; repositorios separados para frontend y backend. |
| Decisión | Un repositorio con backend, frontend, infra y docs; backend FastAPI por capas y módulos de dominio. |
| Justificación | Transacciones locales, un despliegue y pruebas de integración simples. |
| Consecuencias positivas | Contrato único y trazabilidad de commits por historia. |
| Consecuencias negativas | Hay que vigilar que los módulos no se acoplen. |
| Riesgos | Crecimiento desordenado de los servicios; se controla en revisión. |
| Fecha y responsables | 15/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Ninguna |
