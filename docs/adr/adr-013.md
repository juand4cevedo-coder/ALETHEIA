# ADR-013. Herramientas de calidad y verificación continua

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | Un solo desarrollador sin revisión por pares. |
| Drivers | DRV-010 |
| Alternativas | ESLint y Pyright. |
| Decisión | Ruff y mypy estricto en Python; Oxlint, Prettier y TypeScript estricto en el frontend; check obligatorio CI aprobada; CodeQL y Dependabot. |
| Justificación | Oxlint viene con la plantilla oficial de Vite y es un solo binario; mypy es el criterio único de tipos, en el editor y en la CI. |
| Consecuencias positivas | Revisión automática de cada cambio. |
| Consecuencias negativas | Oxlint tiene menos reglas que ESLint. |
| Riesgos | Cambios de comportamiento entre versiones; se fijan versiones exactas. |
| Fecha y responsables | 22/10/2026, Juan Diego Acevedo Calderon |
| Decisión que reemplaza / es reemplazada por | Reemplaza la mención a Pyright y ESLint del plan inicial |
