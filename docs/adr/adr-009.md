# ADR-009. UUID versión 7 y paginación por cursor

| Campo | Contenido |
| --- | --- |
| Estado | Aceptado |
| Contexto | El instructor exige UUID y los listados crecen. |
| Drivers | DRV-005, DRV-007 |
| Alternativas | UUID v4; paginación por desplazamiento. |
| Decisión | Claves primarias UUID v7 y listados con next_cursor. |
| Justificación | v7 conserva el orden de inserción en los índices. |
| Consecuencias positivas | Paginación estable y eficiente. |
| Consecuencias negativas | Los UUID no son secretos; la autorización sigue siendo obligatoria. |
| Riesgos | Disponibilidad nativa en Python por confirmar (DT-004). |
