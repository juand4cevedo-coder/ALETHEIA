# Aletheia 0.5.0

La nueva identidad visual reúne la portada, el acceso, el espacio de trabajo y los correos con una paleta de marfil, azul tinta y latón.

- La portada presenta una huella grabada con movimiento continuo y una variante estática para movimiento reducido.
- Los formularios y las pantallas de casos y auditoría se adaptan a anchos estrechos.
- Se retiraron recursos visuales y componentes sin uso. Los detalles del sistema y del uso de imágenes están en docs/diseno.

La publicación usa la etiqueta firmada v0.5.0 sobre develop y el entorno production. Después del despliegue se comprueban la versión de la API, la salud del servicio y la portada pública.
